How this works

This tool builds the two files Songs of Conquest's random map generator reads: a layout (regions, connections, spawn points) and a blueprint (what objects those spawn points can contain). See the official page for the full spec: songsofconquest.com/modding/rmg.

Layout tab

  • Each map can have several sub-layouts (picked randomly at generation time) — manage them in the left sidebar.
  • Nodes are the big regions placed on the map (drag them). Child regions orbit their parent and represent smaller nearby spawn points, drawn automatically in a ring.
  • Use + Connection / + Portal above the map, then click two nodes/regions to link them.
  • A node's circle size is only an approximate stand-in for its fill value — the game grows each region's real shape procedurally.
  • Select a node and click Mirror to create a symmetric copy for another player whose children stay in sync via shared group numbers — the same trick the official examples use.
  • Press Delete to remove the current selection, Esc to deselect or cancel an add-mode.

Blueprint tab

  • Regions are pools of possible spawns, referenced from the layout by identifier (e.g. player_start, treasure_high).
  • The graph shows each region's fallback chain — where the generator looks if a region fails to spawn.
  • An entry is a group of objects with shared rules (location, guard, difficulty). Repeat an object or guard tier to weight it more heavily.
  • Bonus objects on an entry are extra pickups spawned alongside its main object(s).

Getting unstuck on a field

  • Most fields have a short hint underneath explaining what it does and what values are typical.
  • Numbers, ranges and sliders often show quick-pick chips (e.g. "Player town", "Treasure (high)") — every one is a real value taken from Lavapotion's own example maps, not a guess. Click one, then fine-tune if you like.
  • Fields like region identifier, primary building, and blueprint objects show a described dropdown first ("name — what it does"), grouped by theme, with a plain text box underneath for typing something custom.

Tips

  • Scroll to zoom the map, drag empty space to pan.
  • region_identifier and primary_building accept several entries — the generator randomly weights repeats.
  • Use Load example to start from one of Lavapotion's own reference maps, exactly as the official docs recommend.
